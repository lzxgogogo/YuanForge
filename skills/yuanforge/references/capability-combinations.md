# 可选能力组合

YuanForge 不内置领域执行能力。只有当前证据无法可靠读取时，才根据缺口推荐额外 Skill 或工具；推荐不等于已安装或可用。

| 证据缺口 | 可推荐的能力组合 | 能补充什么 |
|---|---|---|
| Web、桌面或交互式运行时 | Browser 类 Skill + 仓库源码/测试 | 可见页面、真实跳转、反馈和异常状态 |
| Word 或协作文档 | Documents 类 Skill | 文档内容、结构、批注和渲染结果 |
| PDF 产物或表单 | PDF 类 Skill | 页面、文本、表单字段和视觉布局 |
| PPT 或演示讲义 | Presentations 类 Skill | 讲义结构、目标素材和版本差异 |
| XLSX、CSV、TSV 或数据字典 | Spreadsheets 类 Skill | 表结构、公式、数据质量和可复查单元格 |
| 外部来源与研究材料 | 只读 Web 工具或适用连接器 | 来源、时间、引用和冲突证据 |

推荐时说明：缺少什么证据、建议能力能回答什么、安装后仍不能证明什么。用户未要求安装时只给建议；能力不可用时使用仓库证据降级，并报告 `PARTIAL` 或 `BLOCKED`。

新能力不得接管 YuanForge 的就绪判断，也不得直接建立第二套项目事实源。确认后的长期事实仍写入项目稳定文档。
